# Hotel Rate Shopper

[Открыть дашборд](https://aaashtray.github.io/hotel-rate-shopper/)
· [Статистика](https://aaashtray.github.io/hotel-rate-shopper/hotel-statistics-otello.html)

Сравнение гостиничных тарифов Отелло, Ozon Travel, Островка и Яндекса.
Фильтры по стране, географии, звёздам, площадке и условиям тарифа; HTML, CSV и Excel.
Интерфейс работает на телефоне и компьютере без входа.

## Текущий срез

Наблюдения от 10 ноября 2026. Проживание 20–22 ноября 2026, 2 взрослых, 1 номер.
30 отелей: Москва 10, Санкт-Петербург 5, Сочи 5, Мальдивы 4, Таиланд 3, Турция 3.
В открытой версии 1 126 публичных тарифов. 86 цен из авторизованной сессии Яндекса
не опубликованы. Cookies, токены, скриншоты, полные снимки страниц, история SQLite
и исходные данные личных сессий в репозиторий не входят.

Предварительная статистика: 49 из 90 пар отель × конкурент, 17 потенциальных
проигрышей Отелло, 21 преимущество, 11 равных цен. Условия тарифов могут различаться.
Строгих подтверждённых сравнений пока нет. Регистрационный ID используется в
локальном сопоставлении; в публичных таблицах его нет.

Это сохранённый срез. Открытие страницы не запускает сбор цен. Регулярное обновление
пока не настроено. GitHub Pages раздаёт готовые HTML, а Python-сборщик выполняется
отдельно. Яндекс пока поддерживается через ручную транскрипцию наблюдаемой страницы;
автоматический сбор Яндекса не готов. CAPTCHA и ограничения площадок не обходятся.

## Локальная разработка и сбор

```bash
uv sync --extra dev --extra browser
uv run playwright install chromium
uv run rate-shopper collect --output data/browser
uv run rate-shopper report-batch --output reports/latest
```

Сценарий задаётся в `config/scenario.json`, проверенные ссылки отелей — в
`config/hotels.json`. Исходные наблюдения сохраняются локально и исключены из Git.
`PARTIAL_SUCCESS` возвращает код 1, `FAILED` — 2; это бизнес-статус полноты данных.
Перед сбором на новых датах нужно изменить сценарий и проверить доступность источников.

## Обновление открытой версии

После проверки нового локального отчёта:

```bash
uv run python -m rate_shopper.reporting.publication reports/latest/report.json site
```

Экспорт создаёт HTML и JSON только с явно публичными ценами без авторизации,
сохраняет методику статистики и удаляет приватные снимки и служебные URL-параметры.
Excel обновляется отдельно `scripts/export-xlsx.mjs` в среде с `@oai/artifact-tool`.
При смене среза нужно обновить и Excel до публикации, чтобы данные совпадали.
После проверки — commit и push в `main`. Workflow `Publish dashboard` публикует
только папку `site/`. Его можно повторить вручную через GitHub Actions.
Workflow не содержит расписания и не собирает цены самостоятельно.

```bash
uv run pytest -q
uv run ruff check src tests
uv run mypy src
python3 -m http.server 8766 --directory site
```

Публичный набор тестов содержит синтетические случаи расчётов, сопоставления и
защиты публикации. Проверки на снимках личных сессий остаются в локальном проекте.
Палитра и шрифты предоставлены владельцем проекта; сайт не является официальным
сервисом Отелло или других перечисленных площадок.
