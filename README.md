# Hotel Rate Shopper

[Открыть дашборд](https://aaashtray.github.io/hotel-rate-shopper/)
· [Статистика](https://aaashtray.github.io/hotel-rate-shopper/hotel-statistics-otello.html)
· [Карта](https://aaashtray.github.io/hotel-rate-shopper/hotel-map-otello.html)

Сравнение гостиничных тарифов Отелло, Ozon Travel, Островка и Яндекса.
Фильтры по стране, географии, звёздам, площадке и условиям тарифа; HTML, CSV и Excel.
Интерфейс работает на телефоне и компьютере без входа.

## Текущий срез

Наблюдения от 10 ноября 2026. Проживание 20–22 ноября 2026, 2 взрослых, 1 номер.
100 отелей: 55 в России и 45 за рубежом. В выборке 38 российских регионов и
38 зарубежных стран. Последнее расширение: 25 новых российских направлений
(в том числе Якутск, Южно-Сахалинск, Петропавловск-Камчатский, Уфа и Пермь)
и 25 новых стран, включая Японию, Китай, Малайзию, Индию, европейские страны,
Марокко и ЮАР.
Опубликованы все 6 892 собранных тарифа: Отелло — 1 418, Ozon — 1 859,
Островок — 3 529, Яндекс — прежние 86 тарифов из авторизованной сессии.
У всех 50 новых отелей есть цены Отелло и минимум одного конкурента.
Новый сбор Яндекса отложен по просьбе владельца. Прежние 3 376 тарифов сохранены
без изменений. Из 400 наблюдений проверено 301: у 291 есть цены, у 10 явно нет
номеров, 99 остаются незавершёнными (включая отложенный Яндекс и ненайденные карточки).
Cookies, токены, скриншоты, полные снимки страниц, история SQLite
и исходные данные личных сессий в репозиторий не входят.

Предварительная статистика по всем ценам: 170 из 300 пар отель × конкурент,
89 потенциальных проигрышей Отелло, 35 преимуществ, 46 равных цен. Яндекс
сохранён в расчётах. Есть три режима: все цены, без Пэй/корпоративных, публичные.
Публичный срез: 155 пар, 78 проигрышей, 31 преимущество, 46 равных цен.
Hilton Baku не участвует в расчёте разрыва до сверки разных адресов источников;
все его собранные цены доступны в тарифах. Известные доплаты также исключают пару.
Условия тарифов и доступ к цене могут различаться.
Строгих подтверждённых сравнений пока нет. Регистрационный ID используется в
локальном сопоставлении; в публичных таблицах его нет.

Это сохранённый срез. Открытие страницы не запускает сбор цен. Регулярное обновление
пока не настроено. GitHub Pages раздаёт готовые HTML, а Python-сборщик выполняется
отдельно. Яндекс пока поддерживается через ручную транскрипцию наблюдаемой страницы;
автоматический сбор Яндекса не готов. CAPTCHA и ограничения площадок не обходятся.

## Локальная разработка и сбор

```bash
uv sync --extra dev --extra browser
uv run playwright install chromium
uv run rate-shopper collect --output data/browser
uv run rate-shopper report-batch --output reports/latest
```

Сценарий задаётся в `config/scenario.json`, проверенные ссылки отелей — в
`config/hotels.json`. Исходные наблюдения сохраняются локально и исключены из Git.
`PARTIAL_SUCCESS` возвращает код 1, `FAILED` — 2; это бизнес-статус полноты данных.
Перед сбором на новых датах нужно изменить сценарий и проверить доступность источников.

## Обновление открытой версии

После проверки нового локального отчёта:

```bash
uv run python -m rate_shopper.reporting.publication reports/latest/report.json site --include-conditional
```

Экспорт создаёт HTML и JSON со всеми собранными ценами по разрешению владельца,
сохраняет тип доступа и удаляет приватные снимки и служебные URL-параметры.
Без флага `--include-conditional` экспорт содержит только публичные цены.
В полном экспорте статистика содержит три отдельных режима доступа к цене.
Публичный экспорт оставляет только публичную статистику. Подтверждённые сравнения
не смешиваются с предварительными минимумами.
Excel обновляется отдельно `scripts/export-xlsx.mjs` в среде с `@oai/artifact-tool`.
При смене среза нужно обновить и Excel до публикации, чтобы данные совпадали.
После проверки — commit и push в `main`. Workflow `Publish dashboard` публикует
только папку `site/`. Его можно повторить вручную через GitHub Actions.
Workflow не содержит расписания и не собирает цены самостоятельно.

```bash
uv run pytest -q
node --test tests/*.test.mjs
uv run ruff check src tests
uv run mypy src
python3 -m http.server 8766 --directory site
```

Публичный набор тестов содержит синтетические случаи расчётов, сопоставления и
защиты публикации. Проверки на снимках личных сессий остаются в локальном проекте.
Палитра и шрифты предоставлены владельцем проекта; сайт не является официальным
сервисом Отелло или других перечисленных площадок.

Подпись «Похожий тариф» означает совпадение известных основных условий. Неизвестные
поля не считаются различием. «Почему такая оценка?» перечисляет совпадения, различия
и неподтверждённые условия. Это не заменяет строгую проверку сопоставимости.

## География и фильтры

Карта России показывает регионы; карта мира — страны. Москва и Санкт-Петербург
относятся к отдельным городам, Сочи — к Краснодарскому краю. Серый цвет означает
отсутствие отелей по фильтрам, штриховка — наличие отелей без допустимых сравнений.
Зелёный — Отелло дешевле, красный — дороже; точный ноль выделен отдельно.
Показатель региона — медиана медианных разрывов каждого отеля к выбранным конкурентам.
Так отель с тремя конкурентами не перевешивает отель с одним. Клик открывает состав
выборки и тарифы; это не оценка всего рынка региона.

Фильтры закреплены рядом с результатами на компьютере и сворачиваются на телефоне.
Активные фильтры отражаются в URL и сохраняются при переходах между разделами.
Карты можно увеличить на телефоне; Excel содержит срез по всем типам цен.
В плотных участках карты подписи скрываются, чтобы не перекрывать друг друга;
все территории доступны по нажатию и в списке. Подпись выбранной территории
имеет приоритет. Российские подписи показывают город нашей выборки.

Геометрия: Natural Earth 5.1.1, public domain; источник и атрибуция встроены в карту.
Крым, Севастополь, Донецкая, Луганская, Запорожская и Херсонская области
не входят в слой России; на мировой карте относятся к Украине.
Для воспроизведения: `uv run scripts/build-map-geometry.py` (проверяет SHA256).
HTML встраивает данные, геометрию и шрифты. Для офлайн-переходов положите
`hotel-interface-otello.html`, `hotel-statistics-otello.html`, `hotel-map-otello.html`
и `hotel-rates.xlsx` в одну папку.
